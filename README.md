## 📱 About the App

This app calculates:

- 📍 The distance of a trip
- ⛽ The car's average fuel consumption (km/l)
- 💰 The fuel price

Based on this data, the app calculates how much fuel will be used and the total cost of the trip.

All the logic is written purely in Kotlin, with no external libraries or advanced frameworks, specifically to reinforce the fundamentals.

## 🧩 Technologies and Concepts Used

This project uses only traditional Android fundamentals, making it ideal for beginners:

- Kotlin
- Activities
- UI with XML
- TextView
- EditText
- Button
- Field validation
- Navigation between screens with Intent
- Data passing between screens with Bundle
- Toolbar
- Basic organization of layouts and screens
